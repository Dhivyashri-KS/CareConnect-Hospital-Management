CareConnect Hospital Management demo website
=============================================

Files
- index.html: page structure
- style.css: responsive layout and styling
- script.js: navigation, sample records, search, add-record form

How to run in VS Code
1. Extract this ZIP file.
2. Open the extracted `careconnect_website` folder in VS Code.
3. Open `index.html` in a browser, or install the VS Code extension "Live Server".
4. If you use Live Server, right-click index.html and choose "Open with Live Server".

What works
- Dashboard and module navigation
- Sample patient, staff, room, lab, pharmacy and billing records
- Search within each module
- Add-record dialog and status selection
- Epic → Feature → User Story example

Important
This is a frontend-only demo. The records are sample data stored in JavaScript and are not connected to MySQL or Spring Boot. Do not enter real patient information. A backend and database are needed for persistent, secure data.
